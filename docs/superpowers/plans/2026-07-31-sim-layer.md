# Simulation Support Layer Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the `sim/` support layer — the practical tooling around a solve: `linear_guess` (build a sensible initial `z0`), results extraction into named trajectories + CSV export, validation-by-integration (RK4 re-integration vs the collocated solution), and diagnostics (classify a solve outcome into a helpful message).

**Architecture:** These are free functions/small structs over the already-merged types. `linear_guess(model, layout)` builds `z0` by linearly interpolating each state between its pinned initial/final (holding constant when unpinned) and placing controls at their bound midpoint. `extract_trajectory(result, layout, model, mesh)` unpacks the flat solution `z*` into a `Trajectory` (node times + named per-state/per-control series); `write_csv` serializes it. `validate_by_integration(ocp, result, layout)` RK4-integrates the dynamics from the solved node-0 state using the solved control (linearly interpolated), returning the max deviation from the collocated states — the spec's definitive independent check. `diagnose(result[, integration_error])` maps a `SolverResult` to a human-readable diagnosis. Auto-scaling and GUI plotting are deferred (documented follow-ons); CSV export is the headless-friendly form of "results/plotting".

**Tech Stack:** C++17, the merged `goss::ad` + `goss::nlp` + `goss::solver` + `goss::transcription` + `goss::model` layers, GoogleTest, CMake, containerized build via `scripts/dev.sh`.

## Global Constraints

- Language: **C++17**.
- `sim/` consumes existing types only — it adds NO new modeling/solver concepts:
  - `goss::transcription::VariableLayout`: `state_index(node,state)`, `control_index(node,control)`, `num_states()`, `num_controls()`, `num_nodes()`, `total_variables()`.
  - `goss::transcription::Mesh`: `t_initial`, `t_final`, `num_intervals`, `num_nodes()`, `interval_width()`.
  - `goss::transcription::OcpProblem<Dyn,Cost>`: `.dynamics` (callable `template<T> std::vector<T>(const std::vector<T>& x, const std::vector<T>& u, T t)`), `.mesh`, `.num_states`, `.num_controls`.
  - `goss::transcription::CompiledOcp`: `std::unique_ptr<nlp::NLPProblem> problem; VariableLayout layout;`.
  - `goss::solver::SolverResult`: `SolverStatus status; std::vector<double> x; double objective_value; std::vector<double> constraint_multipliers; std::string message;`. `SolverStatus` = `{Success, InfeasibleProblem, IterationLimit, NumericalError, Failure}`.
  - `goss::model::Model`: `num_states()`, `num_controls()`, `state_name(i)`, `control_name(i)`, `state_lower(i)`/`state_upper(i)`, `control_lower(i)`/`control_upper(i)`, `initial_fixed(i)`/`initial_value(i)`, `final_fixed(i)`/`final_value(i)`.
- Free-bound sentinel is `goss::transcription::kInf = 2e19`; bounds with magnitude `>= 1e19` are treated as "infinite" (matches the solver adapters' threshold) — used by `linear_guess` when choosing a midpoint.
- `validate_by_integration` uses RK4 with the mesh's uniform step; the control is linearly interpolated between adjacent nodes (needed at RK4's midpoint samples).
- Error handling per org standard: a `SimError` exception for usage errors (size mismatches, empty result) with meaningful messages. No silent catch-all.
- Coding standards: verbose descriptive variable names; type annotations everywhere; comments explain WHY.
- Container-first build: all `cmake`/`ctest` run inside the container via `scripts/dev.sh '<command>'`. Never build on the host.
- Test framework: **GoogleTest**. Validation-by-integration MUST be tested against an analytic ODE and MUST flag a deliberately corrupted solution (spec requirement). Diagnostics MUST be tested by feeding results of each status.
- **Deferred (documented follow-ons, NOT built):** variable/constraint auto-scaling; GUI/chart plotting (CSV export is the v1 form); benchmark harness.

    - Validates `model.num_states() == layout.num_states()` and `model.num_controls() == layout.num_controls()`, else `SimError`.
    - Returns a `z0` of size `layout.total_variables()`.
    - **States:** for state i, determine an initial value `a` (= `initial_value(i)` if `initial_fixed(i)`, else 0.0) and a final value `b` (= `final_value(i)` if `final_fixed(i)`, else `a`). At node k (of `num_nodes()`), set `z0[state_index(k,i)] = a + (b - a) * k / (num_nodes()-1)` (linear interpolation; constant `a` when unpinned/no final).
    - **Controls:** for control j, use the bound midpoint: if both `control_lower(j)` and `control_upper(j)` are finite (magnitude < 1e19), midpoint `(lo+hi)/2`; else 0.0. Same value at every node.

```cpp
// include/goss/sim/initial_guess.hpp
#pragma once
#include <cmath>
#include <cstddef>
#include <vector>
#include "goss/model/model.hpp"
#include "goss/sim/errors.hpp"
#include "goss/transcription/variable_layout.hpp"

namespace goss::sim {

/// Builds an initial decision vector z0 for a compiled OCP:
///  - each state is linearly interpolated between its pinned initial and final
///    values (held constant at the initial when the final is unpinned, or at 0
///    when neither is pinned);
///  - each control is set to the midpoint of its finite box bounds (0 if a side
///    is infinite).
/// This is a cheap, usually-feasible warm start that converges far more
/// reliably than an all-zeros or all-same-value guess.
inline std::vector<double> linear_guess(const model::Model& model,
                                        const transcription::VariableLayout& layout) {
    if (model.num_states() != layout.num_states())
        throw SimError("linear_guess: model.num_states != layout.num_states");
    if (model.num_controls() != layout.num_controls())
        throw SimError("linear_guess: model.num_controls != layout.num_controls");

    const std::size_t num_nodes = layout.num_nodes();
    std::vector<double> z0(layout.total_variables(), 0.0);

    for (std::size_t i = 0; i < layout.num_states(); ++i) {
        const double a = model.initial_fixed(i) ? model.initial_value(i) : 0.0;
        const double b = model.final_fixed(i) ? model.final_value(i) : a;
        for (std::size_t k = 0; k < num_nodes; ++k) {
            const double fraction = (num_nodes > 1)
                ? static_cast<double>(k) / static_cast<double>(num_nodes - 1) : 0.0;
            z0[layout.state_index(k, i)] = a + (b - a) * fraction;
        }
    }
    for (std::size_t j = 0; j < layout.num_controls(); ++j) {
        const double lo = model.control_lower(j);
        const double hi = model.control_upper(j);
        const bool finite = std::abs(lo) < 1e19 && std::abs(hi) < 1e19;
        const double value = finite ? 0.5 * (lo + hi) : 0.0;
        for (std::size_t k = 0; k < num_nodes; ++k)
            z0[layout.control_index(k, j)] = value;
    }
    return z0;
}

}  // namespace goss::sim
```

```cpp
// include/goss/sim/trajectory.hpp
#pragma once
#include <cstddef>
#include <string>
#include <vector>
#include "goss/model/model.hpp"
#include "goss/sim/errors.hpp"
#include "goss/solver/solver_result.hpp"
#include "goss/transcription/ocp_problem.hpp"       // Mesh
#include "goss/transcription/variable_layout.hpp"

namespace goss::sim {

/// A solved trajectory unpacked from the flat decision vector: node times plus
/// named per-state and per-control series (each series is one value per node).
struct Trajectory {
    std::vector<double> times;
    std::vector<std::string> state_names;
    std::vector<std::string> control_names;
    std::vector<std::vector<double>> states;    // states[i][k]
    std::vector<std::vector<double>> controls;  // controls[j][k]

    const std::vector<double>& state(const std::string& name) const {
        for (std::size_t i = 0; i < state_names.size(); ++i)
            if (state_names[i] == name) return states[i];
        throw SimError("Trajectory::state: unknown state '" + name + "'");
    }
    const std::vector<double>& control(const std::string& name) const {
        for (std::size_t j = 0; j < control_names.size(); ++j)
            if (control_names[j] == name) return controls[j];
        throw SimError("Trajectory::control: unknown control '" + name + "'");
    }
};

inline Trajectory extract_trajectory(const solver::SolverResult& result,
                                     const transcription::VariableLayout& layout,
                                     const model::Model& model,
                                     const transcription::Mesh& mesh) {
    if (result.x.size() != layout.total_variables())
        throw SimError("extract_trajectory: result.x size != layout.total_variables");
    if (mesh.num_nodes() != layout.num_nodes())
        throw SimError("extract_trajectory: mesh.num_nodes != layout.num_nodes");

    const std::size_t num_nodes = layout.num_nodes();
    const double width = mesh.interval_width();
    Trajectory traj;
    traj.times.resize(num_nodes);
    for (std::size_t k = 0; k < num_nodes; ++k)
        traj.times[k] = mesh.t_initial + static_cast<double>(k) * width;

    traj.states.assign(layout.num_states(), std::vector<double>(num_nodes, 0.0));
    traj.state_names.resize(layout.num_states());
    for (std::size_t i = 0; i < layout.num_states(); ++i) {
        traj.state_names[i] = model.state_name(i);
        for (std::size_t k = 0; k < num_nodes; ++k)
            traj.states[i][k] = result.x[layout.state_index(k, i)];
    }
    traj.controls.assign(layout.num_controls(), std::vector<double>(num_nodes, 0.0));
    traj.control_names.resize(layout.num_controls());
    for (std::size_t j = 0; j < layout.num_controls(); ++j) {
        traj.control_names[j] = model.control_name(j);
        for (std::size_t k = 0; k < num_nodes; ++k)
            traj.controls[j][k] = result.x[layout.control_index(k, j)];
    }
    return traj;
}

}  // namespace goss::sim
```

```cpp
// add inside namespace goss::sim, after extract_trajectory
inline std::string to_csv(const Trajectory& traj) {
    std::ostringstream out;
    out << std::setprecision(17);
    out << "time";
    for (const auto& name : traj.state_names) out << "," << name;
    for (const auto& name : traj.control_names) out << "," << name;
    out << "\n";
    for (std::size_t k = 0; k < traj.times.size(); ++k) {
        out << traj.times[k];
        for (const auto& series : traj.states) out << "," << series[k];
        for (const auto& series : traj.controls) out << "," << series[k];
        out << "\n";
    }
    return out.str();
}

inline void write_csv(const Trajectory& traj, const std::string& path) {
    std::ofstream file(path);
    if (!file) throw SimError("write_csv: cannot open '" + path + "' for writing");
    file << to_csv(traj);
```

### Task 4: Validation-by-integration (RK4 vs collocated solution)

**Files:**
- Create: `include/goss/sim/validation.hpp`
- Create: `tests/sim/test_validation.cpp`
- Modify: `CMakeLists.txt` (add test_validation.cpp)

**Interfaces:**
- Consumes: `transcription::OcpProblem<Dyn,Cost>` (its `.dynamics`, `.mesh`, `.num_states`, `.num_controls`), `solver::SolverResult`, `transcription::VariableLayout`.
- Produces:
  - `template <typename DynamicsFn, typename CostFn> double goss::sim::validate_by_integration(const transcription::OcpProblem<DynamicsFn,CostFn>& ocp, const solver::SolverResult& result, const transcription::VariableLayout& layout);`
  - Behavior: independently RK4-integrates the ODE `dx/dt = ocp.dynamics(x, u(t), t)` starting from the SOLVED node-0 state, over the mesh, sampling the control by LINEAR INTERPOLATION between adjacent solved node controls (RK4 needs the control at interval midpoints). At each node k it compares the integrated state to the SOLVED node-k state and returns the **maximum absolute deviation over all states and nodes**. A correctly-solved collocation problem yields a small deviation (bounded by the scheme's discretization error); a corrupted/incorrect solution yields a large one. This is the spec's definitive independent correctness check.
  - Validates `result.x.size() == layout.total_variables()` else `SimError`.

**RK4 detail (per interval k, step h = mesh.interval_width(), evaluated in double):**
- `x_k` = current integrated state (start = solved node-0 state).
- control sampler `u(t)`: find the interval containing t, linearly interpolate each control between its two node values. At exactly node k it equals the node control; at the midpoint it's the average of nodes k and k+1.
- `k1 = f(x_k, u(t_k), t_k)`
- `k2 = f(x_k + (h/2)k1, u(t_k+h/2), t_k+h/2)`
- `k3 = f(x_k + (h/2)k2, u(t_k+h/2), t_k+h/2)`
- `k4 = f(x_k + h*k3, u(t_k+h), t_k+h)`
- `x_{k+1} = x_k + (h/6)(k1 + 2k2 + 2k3 + k4)`
- After each step, deviation at node k+1 = max_i |x_{k+1}[i] - solved_state(k+1,i)|; track the running max.
- The dynamics are called with `std::vector<double>` (double instantiation of the templated functor) — NOT AD.

**Design note:** the control interpolation is the fiddly part. Write a helper `control_at(double t)` capturing the solved controls + layout + mesh: compute the interval index `idx = clamp(floor((t - t0)/h), 0, num_intervals-1)`, local fraction `s = (t - (t0 + idx*h)) / h` clamped to [0,1], and return per-control `u_idx*(1-s) + u_{idx+1}*s`. For a 0-control problem it returns an empty vector.

```cpp
// include/goss/sim/validation.hpp
#pragma once
#include <algorithm>
#include <cmath>
#include <cstddef>
#include <vector>
#include "goss/sim/errors.hpp"
#include "goss/solver/solver_result.hpp"
#include "goss/transcription/ocp_problem.hpp"
#include "goss/transcription/variable_layout.hpp"

namespace goss::sim {

/// Independent RK4 re-integration of the OCP dynamics from the solved node-0
/// state, using the solved controls (linearly interpolated between nodes).
/// Returns the maximum absolute deviation, over all states and nodes, between
/// the re-integrated trajectory and the collocated solution. Small for a
/// correctly-solved problem; large for a corrupted/incorrect one. This is an
/// independent check of the transcription+solve, not a re-run of collocation.
template <typename DynamicsFn, typename CostFn>
double validate_by_integration(const transcription::OcpProblem<DynamicsFn, CostFn>& ocp,
                               const solver::SolverResult& result,
                               const transcription::VariableLayout& layout) {
    if (result.x.size() != layout.total_variables())
        throw SimError("validate_by_integration: result.x size != layout.total_variables");

    const std::size_t ns = layout.num_states();
    const std::size_t nc = layout.num_controls();
    const std::size_t ni = ocp.mesh.num_intervals;
    const double t0 = ocp.mesh.t_initial;
    const double h = ocp.mesh.interval_width();

    // Linear control sampler at arbitrary time t within [t0, t0 + ni*h].
    auto control_at = [&](double t) {
        std::vector<double> u(nc, 0.0);
        if (nc == 0) return u;
        double raw = (t - t0) / h;
        long idx_long = static_cast<long>(std::floor(raw));
        if (idx_long < 0) idx_long = 0;
        if (idx_long > static_cast<long>(ni) - 1) idx_long = static_cast<long>(ni) - 1;
        const std::size_t idx = static_cast<std::size_t>(idx_long);
        double s = (t - (t0 + static_cast<double>(idx) * h)) / h;
        s = std::max(0.0, std::min(1.0, s));
        for (std::size_t j = 0; j < nc; ++j) {
            const double u0 = result.x[layout.control_index(idx, j)];
            const double u1 = result.x[layout.control_index(idx + 1, j)];
            u[j] = u0 * (1.0 - s) + u1 * s;
        }
        return u;
    };

    auto solved_state = [&](std::size_t node, std::size_t i) {
        return result.x[layout.state_index(node, i)];
    };
    auto add_scaled = [&](const std::vector<double>& a, double c, const std::vector<double>& b) {
        std::vector<double> out(ns);
        for (std::size_t i = 0; i < ns; ++i) out[i] = a[i] + c * b[i];
        return out;
    };

    // Start from the solved node-0 state.
    std::vector<double> x(ns);
    for (std::size_t i = 0; i < ns; ++i) x[i] = solved_state(0, i);

    double max_deviation = 0.0;
    for (std::size_t k = 0; k < ni; ++k) {
        const double tk = t0 + static_cast<double>(k) * h;
        const double tm = tk + 0.5 * h;
        const double tk1 = tk + h;
        std::vector<double> k1 = ocp.dynamics(x, control_at(tk), tk);
        std::vector<double> k2 = ocp.dynamics(add_scaled(x, 0.5 * h, k1), control_at(tm), tm);
        std::vector<double> k3 = ocp.dynamics(add_scaled(x, 0.5 * h, k2), control_at(tm), tm);
        std::vector<double> k4 = ocp.dynamics(add_scaled(x, h, k3), control_at(tk1), tk1);
        for (std::size_t i = 0; i < ns; ++i)
            x[i] += (h / 6.0) * (k1[i] + 2.0 * k2[i] + 2.0 * k3[i] + k4[i]);
        for (std::size_t i = 0; i < ns; ++i)
            max_deviation = std::max(max_deviation, std::abs(x[i] - solved_state(k + 1, i)));
    }
    return max_deviation;
}

}  // namespace goss::sim
```

```cpp
// include/goss/sim/diagnostics.hpp
#pragma once
#include <string>
#include "goss/solver/solver_result.hpp"

namespace goss::sim {

struct Diagnosis {
    bool ok;
    std::string summary;
    std::string advice;
};

inline Diagnosis diagnose(const solver::SolverResult& result) {
    using solver::SolverStatus;
    switch (result.status) {
        case SolverStatus::Success:
            return {true, "Solver converged.", ""};
        case SolverStatus::InfeasibleProblem:
            return {false, "Problem detected as infeasible.",
                    "Check that constraints/bounds are consistent (e.g. boundary "
                    "conditions reachable, path bounds not contradictory)."};
        case SolverStatus::IterationLimit:
            return {false, "Iteration limit reached before convergence.",
                    "Try a better initial guess (sim::linear_guess), a finer/coarser "
                    "mesh, or increase max iterations."};
        case SolverStatus::NumericalError:
            return {false, "Numerical error during solve (NaN/Inf).",
                    "Check dynamics/cost for divisions by zero or domain errors; "
                    "verify scaling."};
        case SolverStatus::Failure:
        default: {
            std::string summary = "Solver failed.";
            if (!result.message.empty()) summary += " (" + result.message + ")";
            return {false, summary, "See result.message for the underlying solver status."};
        }
    }
}

inline Diagnosis diagnose(const solver::SolverResult& result,
                          double integration_error,
                          double tolerance = 1e-3) {
    if (result.status == solver::SolverStatus::Success && integration_error > tolerance) {
        return {false,
                "Solver reported success but the solution fails RK4 re-integration "
                "(error " + std::to_string(integration_error) + ").",
                "The discretization may be too coarse — refine the mesh; or the "
                "dynamics may be stiff."};
    }
    return diagnose(result);
}

}  // namespace goss::sim
```
