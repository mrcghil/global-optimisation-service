# AD Layer Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the `ad/` layer — a backend-agnostic automatic-differentiation interface plus a CppADCodeGen implementation that records a function, detects Jacobian/Hessian sparsity, generates and JIT-compiles C derivative code, and evaluates fast sparse ∇f, Jacobian, and Hessian.

**Architecture:** A user supplies a *templated functor* (`template<typename T> operator()(const std::vector<T>&) const`) so the same function instantiates as `AD<CG<double>>` for recording, `double` for finite differences, and `std::complex<double>` for complex-step checks. An abstract `ADBackend` interface exposes evaluation + sparsity; `CppADCGBackend` implements it by recording an `ADFun`, extracting sparsity, generating C via `ModelCSourceGen`, compiling with `GccCompiler`, and loading a `GenericModel`. Verification helpers (FD, complex-step) live in shared test utilities.

**Tech Stack:** C++17, CppAD + CppADCodeGen, Eigen (sparse types), GoogleTest, CMake with FetchContent.

## Global Constraints

- Language: **C++17**.
- AD backend (v1): **CppAD + CppADCodeGen**; codegen compiled via **GccCompiler**.
- All derivatives MUST be **sparse** (values + sparsity pattern), never dense-only.
- The `ADBackend` interface MUST NOT expose any CppAD-specific type — it must be swappable (e.g. Enzyme later).
- Test framework: **GoogleTest**; derivative verification via **finite-difference and complex-step** helpers.
- Coding standards: verbose descriptive variable names; type annotations everywhere the language allows; specific exception types with meaningful messages, no silent catch-all.
- Sparsity-pattern correctness is a first-class tested property (a wrong pattern is a silent bug).
- **Container-first build**: all dependencies (g++, cmake, CppAD, CppADCodeGen, Eigen) live inside a container image, never installed system-wide on the host. Every task's `cmake`/`ctest` commands run **inside the container** via `scripts/dev.sh`. This enables remote/CI dispatch. `GccCompiler` JIT uses the container's native `g++`.
- Two container surfaces: a **devcontainer** (`.devcontainer/`) for local development, and a **Dockerfile + docker-compose.yml** for a production-realistic CI pipeline. Both derive from the same base build stage to avoid drift.

```cpp
#pragma once
#include <cmath>
#include <cstddef>
#include <vector>

namespace goss::ad::test {

struct Quadratic {
    std::size_t n;
    explicit Quadratic(std::size_t num_inputs) : n(num_inputs) {}
    std::size_t input_size() const { return n; }
    std::size_t output_size() const { return 1; }
    template <typename T>
    std::vector<T> operator()(const std::vector<T>& x) const {
        T accumulator = T(0);
        for (const auto& value : x) accumulator += value * value;
        return {T(0.5) * accumulator};
    }
};

struct Rosenbrock {
    std::size_t input_size() const { return 2; }
    std::size_t output_size() const { return 1; }
    template <typename T>
    std::vector<T> operator()(const std::vector<T>& x) const {
        T a = T(1) - x[0];
        T b = x[1] - x[0] * x[0];
        return {a * a + T(100) * b * b};
    }
};

struct Banded {
    std::size_t n;
    explicit Banded(std::size_t size) : n(size) {}
    std::size_t input_size() const { return n; }
    std::size_t output_size() const { return n; }
    template <typename T>
    std::vector<T> operator()(const std::vector<T>& x) const {
        std::vector<T> y(n);
        for (std::size_t i = 0; i < n; ++i) {
            T next = (i + 1 < n) ? x[i + 1] : T(0);
            y[i] = x[i] * x[i] + next;  // depends on x[i], x[i+1]
        }
        return y;
    }
};

struct Trig {
    std::size_t input_size() const { return 2; }
    std::size_t output_size() const { return 2; }
    template <typename T>
    std::vector<T> operator()(const std::vector<T>& x) const {
        using std::sin; using std::cos;
        return {sin(x[0]) * x[1], cos(x[1])};
    }
};

}  // namespace goss::ad::test
```

```cpp
// tests/ad/verification.hpp
#pragma once
#include <cstddef>
#include <vector>

namespace goss::ad::test {

template <typename F>
std::vector<std::vector<double>> finite_difference_jacobian(
    const F& f, const std::vector<double>& x, double step = 1e-6) {
    const std::size_t n = x.size();
    const std::size_t m = f(x).size();
    std::vector<std::vector<double>> jacobian(m, std::vector<double>(n, 0.0));
    for (std::size_t j = 0; j < n; ++j) {
        std::vector<double> x_plus = x, x_minus = x;
        x_plus[j] += step;
        x_minus[j] -= step;
        auto y_plus = f(x_plus);
        auto y_minus = f(x_minus);
        for (std::size_t i = 0; i < m; ++i) {
            jacobian[i][j] = (y_plus[i] - y_minus[i]) / (2.0 * step);
        }
    }
    return jacobian;
}

}  // namespace goss::ad::test
```

```cpp
// add to tests/ad/verification.hpp
#include <complex>

namespace goss::ad::test {

template <typename F>
std::vector<std::vector<double>> complex_step_jacobian(
    const F& f, const std::vector<double>& x, double step = 1e-20) {
    using Complex = std::complex<double>;
    const std::size_t n = x.size();
    std::vector<Complex> x_complex(n);
    for (std::size_t j = 0; j < n; ++j) x_complex[j] = Complex(x[j], 0.0);
    const std::size_t m = f(x_complex).size();
    std::vector<std::vector<double>> jacobian(m, std::vector<double>(n, 0.0));
    for (std::size_t j = 0; j < n; ++j) {
        auto perturbed = x_complex;
        perturbed[j] = Complex(x[j], step);
        auto y = f(perturbed);
        for (std::size_t i = 0; i < m; ++i) {
            jacobian[i][j] = y[i].imag() / step;
        }
    }
    return jacobian;
}

}  // namespace goss::ad::test
```

```cpp
// src/ad/cppadcg_backend.cpp
#include "goss/ad/cppadcg_backend.hpp"
#include <cppad/cg/model/model_c_source_gen.hpp>
#include <cppad/cg/model/model_library_c_source_gen.hpp>
#include <cppad/cg/model/dynamic_model_library_processor.hpp>
#include <cppad/cg/c/gcc_compiler.hpp>

namespace goss::ad::detail {

CompiledModel compile_and_load(CppAD::ADFun<CGScalar>& fun,
                               const std::string& model_name) {
    try {
        CppAD::cg::ModelCSourceGen<double> source_gen(fun, model_name);
        source_gen.setCreateJacobian(true);
        source_gen.setCreateHessian(true);
        source_gen.setCreateSparseJacobian(true);
        source_gen.setCreateSparseHessian(true);
        source_gen.setCreateForwardZero(true);

        CppAD::cg::ModelLibraryCSourceGen<double> library_gen(source_gen);
        CppAD::cg::GccCompiler<double> compiler;
        CppAD::cg::DynamicModelLibraryProcessor<double> processor(library_gen, model_name);

        CompiledModel result;
        result.library = processor.createDynamicLibrary(compiler);
        result.model = result.library->model(model_name);
        if (!result.model) {
            throw ADError("failed to load generated model: " + model_name);
        }
        return result;
    } catch (const CppAD::cg::CGException& error) {
        throw ADError(std::string("CppADCodeGen failure: ") + error.what());
    }
}

}  // namespace goss::ad::detail
```
